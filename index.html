Selected Projects

Visual Representations for Planning: A DINO-WM Study

Computer Vision, NYU · Nov–Dec 2025

code / report

Reproduced DINO-WM for Push-T manipulation and compared DINOv2 and DINOv3 through encoder and decoder ablations. Lower latent prediction loss did not improve downstream planning under the fixed MPC/CEM configuration, motivating further study of representation geometry and the prediction–control mismatch.

Building a Task-Specific JEPA World Model

Deep Learning, NYU · Yann LeCun · Apr–May 2025

code / presentation

Built a 3.63M-parameter, action-conditioned JEPA model on 2.5M offline trajectories in a two-room environment. Used Barlow Twins warmup, MSE alignment, and encoder freezing to prevent collapse, and evaluated generalization to new layouts and longer rollouts.

Ranked second overall and achieved the best model performance in the course competition.

Credit Default Prediction with Relational Data

Machine Learning, NYU · Oct–Dec 2024

code / report

Integrated seven Home Credit tables and compared logistic regression, random forests, and LightGBM. Five-fold cross-validation and focal loss improved ROC-AUC from 0.7918 to 0.8175.
